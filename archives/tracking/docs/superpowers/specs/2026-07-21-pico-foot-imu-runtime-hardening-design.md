# PICO + 双 IMU900 运行时加固设计

## 目标

修复实机运行中三类风险：标定期间脚部移动导致基线污染、IMU 尚未稳定时被用于融合、串口断开后节点无法恢复。

## 方案

1. 标定样本同时检查骨盆、左右 PICO 脚和左右 IMU 的相邻姿态变化；超过阈值时清空样本并重新采集。
2. `imu_ros2` 为每个通道提供 ready 状态。首次有效四元数建立连续性参考后置 ready；收到无效帧或串口异常时清除 ready。融合节点只接受两路 ready 且新鲜的 IMU 数据。
3. 每个 IMU 通道独立维护串口重连定时器。打开失败、读写失败或断开后关闭旧句柄，按固定间隔重开并重发启动命令；通道恢复后重新等待有效姿态。

## 验证

- 单元测试覆盖脚部姿态移动会重启标定、ready 门控和无效/断线后的恢复。
- 保留原版 IMU900 协议测试和 PICO 融合测试。
- 运行完整构建、`colcon test-result`，并验证双串口 launch 参数。
